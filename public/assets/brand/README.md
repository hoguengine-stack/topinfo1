# Brand support assets

`google.svg` is the Google sign-in icon distributed with FirebaseUI:

`https://www.gstatic.com/firebasejs/ui/2.0.0/images/auth/google.svg`

The original TOPINFO logo is implemented separately in `BrandLogo.tsx` and must not be replaced by files in this directory.

`topinfo-mark.svg` is a direct static rendering of the existing `BrandLogo` mark for browser favicon use: white fill, `#0f62fe` circular border, and the Georgia `T`. It must stay visually identical to the React logo mark.
