## 통과한 기반

- 사이트 프레임 1560px, 콘텐츠 1320px 토큰은 코드에 구현되어 있다.
- 미검증 레거시 34,000원 가격을 공개하지 않도록 방어 로직이 있다.
- U+ 앱 예시는 실제 고객 데이터가 아님을 밝히고 가짜 성과 수치를 제거했다.
- 업종별 정책은 과거의 잘못된 영수증·후기·생성 스캔 이미지를 기본 미디어에서 차단한다.
- 홈과 U+ 페이지는 전화 문의와 상담 CTA의 목적을 구분한다.

이 항목들은 기반 구현에 대한 PASS이며, 전체 시각 품질 통과를 의미하지 않는다.

## 수정 우선순위

1. 활성 Toss·U+·생성 에셋의 출처·권리·모델·원본 정보를 등록하고 미확인 파일은 공개 경로에서 차단한다.
2. APEXA X 공식 투명 팩샷과 고해상도 Toss POS 화면을 확보해 패널 비율에 맞춰 다시 합성한다.
3. APEXA X, Toss Front, CPP-3000, 금전함의 실제 치수 기반 상대 비율과 공통 바닥선을 적용한다.
4. U+ 레거시 CSS를 제거·격리하고 IP-520GA/AI전화/손님 메모 문구의 공식 근거를 확정한다.
5. 생성 인물·로봇·CCTV 이미지의 역할을 장식/예시로 제한하고 실제 사례처럼 보이는 표현을 제거한다.
6. 8~11px 공개 텍스트를 정리하고 제품 증거용 이미지는 모바일에서도 전체 실루엣이 보이게 한다.
7. 별도 QA 작업에서 320~2560, 125%·150%, 키보드, reduced motion을 실제 렌더로 검증한다.

## 재심사에 필요한 증거

- 실물 치수 표와 같은 평면 상대 크기 계산표

- 업종 animated image의 첫·중간·마지막 프레임 및 오류 대체 증거

## 감사 한계

이번 작업은 사용자 지시대로 빌드, 전체 테스트, 브라우저 조작을 수행하지 않았다. 따라서 CSS 계약의 존재는 확인했지만 실제 픽셀 결과, 애니메이션 재생, 포커스 이동, 브라우저별 글꼴 렌더링은 승인하지 않았다. 이 제한으로 인해 렌더 증거가 필요한 항목은 추정 PASS가 아니라 **BLOCKED**로 남겼다.
